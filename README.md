Talent SKULLVI by JM

Application web de gestion et de qualification des candidatures.

Présentation du projet

Talent Engine est une mini-application web conçue pour faciliter la réception, l'organisation et la qualification des candidatures. Elle vise à simplifier la collecte des informations des candidats et à faciliter le suivi des profils.

Ce projet est réalisé dans le cadre du mini-challenge de recrutement de SKULLVI.

Objectifs

- Centraliser les candidatures.
- Collecter les informations essentielles des candidats.
- Faciliter la qualification des profils.
- Améliorer le suivi et l'organisation des candidatures.

Technologies utilisées

- PHP : traitement côté serveur.
- MySQL : stockage et gestion des données.
- HTML5 : structure des pages.
- CSS3 : mise en forme et design.
- JavaScript : interactions dynamiques.

Fonctionnalités

- Réception et enregistrement des candidatures.
- Collecte des informations des candidats.
- Gestion et consultation des profils.
- Qualification et suivi des candidatures.

Remarque : conserver uniquement les fonctionnalités réellement implémentées dans la version actuelle.

Structure du projet

La structure exacte dépend de l'organisation des fichiers du projet. Les principaux éléments comprennent les fichiers PHP, les feuilles de style CSS, les scripts JavaScript et le fichier SQL de la base de données.

Installation en local

1. Installer XAMPP ou un environnement compatible avec PHP et MySQL.
2. Copier le dossier du projet dans le répertoire "htdocs".
3. Démarrer Apache et MySQL.
4. Ouvrir phpMyAdmin.
5. Créer la base de données et importer le fichier SQL fourni dans le projet.
6. Configurer la connexion à la base de données.
7. Ouvrir l'application dans le navigateur à l'adresse locale correspondant au nom du dossier.
